# OnebotConnect
轻量的转发模组，onebot协议端与minecraft服务器的连接器
## 特性
- 双向互通，游戏消息可转发至目标群聊，目标群聊的聊天也可转发至服务器
- 玩家进服通报，玩家加入/退出服务器时，也可以在群里通知
- 游戏事件转发，支持游戏死亡事件和成就转发到聊天群内
- 连接反馈，连接成功会在群里发送一条状态通知
- 指令管理，用指令可以操作大多数功能
- 轻量可移植，本模组的逻辑协议部分与游戏完全解耦，自行实现了一个标准kotlin onebot协议库，向上向下可移植性好
- 兼容性好，模组对游戏无侵入式破坏性修改（甚至没有mixin），理论能与绝大多数模组共同运行
## 为何选它？
- 你希望让服务器和你的群聊能双向对话，不再是两个信息孤岛
- 你不想用同类的带独立程序的闭源重量级方案，也用不到那么多功能
- 你希望在模组端而不是插件端实现这个功能
- 多人联机的时候在好兄弟的mc小群里同步消息
- 因前辈的项目停更而逃难的（
## 装在哪？
- 如果你是服务器运营者，那么把它装在你的服务器上就可以了，玩家不用安装
- 如果你是多人联机玩家，那么请把模组安装在局域网游戏的房主客户端上即可运行，其他玩家不用安装
- 如果你喜欢在单人游戏的时候让消息同步到群里，那也可以用这个（真的有人这么做吗？）
如果在不必要的时候安装了此模组，此模组无法发挥任何效用
## 怎么把消息转发到群里？
光安装本模组是没用的，你需要寻找一个适配正向websocket协议（websocket服务器模式）的onebotv11协议端进行使用，为了***保护相关开源项目***，本文不再赘述协议端可用项目，也请不要在issue内提起相关事项，求你们了
## 怎么用？
首先他肯定要先装进你的mods文件夹，根据正确的加载器选择模组文件，然后用下面的指令可以临时操作：

| 命令                                         | 作用                    | 示例                                                     |
| ------------------------------------------ | --------------------- | ------------------------------------------------------ |
| /onebotconnect status                      | 输出当前状态                |                                                        |
| /onebotconnect connect                     | 立刻连接websocket服务器      |                                                        |
| /onebotconnect setwebsocketip < ip >       | 临时设定目标websocket服务器的ip | /onebotconnect setwebsocketip 127.0.0.1                |
| /onebotconnect setwebsocketport < port >   | 临时设定目标websocket服务器的端口 | /onebotconnect setwebsocketport 6700                   |
| /onebotconnect setwebsocketpath < path >   | 临时设定目标websocket服务器的路径 | /onebotconnect setwebsocketpath /ws                    |
| /onebotconnect setwebsockettoken < token > | 临时设定目标websocket服务器的密钥 | /onebotconnect setwebsockettoken crazythursdayvme50kfc |
| /onebotconnect disconnect                  | 断开websocket服务器连接      |                                                        |
| /onebotconnect reload                      | 重载模组配置，清除临时设定         |                                                        |
- 为了安全起见和避免恶意行为，控制台操作的websocket相关配置不会被写入配置文件，需要永久修改配置请去config/onebotconnect.json修改配置文件。
- 所有命令需要2及以上权限才可执行
## 版本支持情况

| 版本           | 加载器             | 支持情况 | 说明       |
| ------------ | --------------- | ---- | -------- |
| 26.2+        | NeoForge/Fabric | 计划支持 | 正式版出后移植  |
| 26.1.2       | NeoForge/Fabric | 完全支持 | 当前测试版    |
| 1.21.10~26.1 | NeoForge/Fabric | 计划支持 | 正式版推出后移植 |
| 1.21.1       | Neoforge/Fabric | 计划暂缓 |          |

除此之外无任何向下移植计划，不计划支持任何版本的Forge/Quilt/Cleanroom等加载器
## 相关问题
- **Q1: 每次用命令设置配置，重启之后就丢失了怎么办？**
- 这是预期行为，为了安全考虑，所有配置不会被写入配置文件，保证服务器实际拥有者具备完全控制权，以防op被意外获取后发生灾难性事故
- **Q2: 支持什么版本？**
- 当前支持26.1.2，计划支持1.21.10+，暂缓1.21.1
- **Q3: 为什么不支持1.20.1，1.12.2这类热门版本，我真的很需要！**
- 为什么不试试我们的前辈[mcbot](https://www.mcmod.cn/class/4903.html)呢？
- **Q4: 为什么不支持Forge,Quilt？是不是歧视！**
- 因为只打算做用的人多的这些平台，然后就是也没有插件服的适配计划
